# ДЗ 4. Full FT и LoRA

[Отчёт](report.md) · [Код](train.py) · [Результаты](results/)

Для воспроизведения установите requirements.txt в отдельный venv и запустите из этой папки:

    CUDA_VISIBLE_DEVICES=0 bash run_all.sh

Скрипт скачает SST-2 и Qwen2.5-1.5B-Instruct, восстановит выборки и выполнит все семь запусков. Версии модели и датасета закреплены в data_manifest.json. Каждый вариант запускается в новом процессе. Для повторного запуска используйте чистую копию папки results: существующие результаты защищены от перезаписи. Достаточно одной A100 40 GB.

Accuracy и macro-F1 рассчитываются по свободной жадной генерации ответа positive или negative. Другой ответ считается ошибкой. Веса после запусков не сохраняются; код воспроизводит обучение и оценку с нуля из одной предобученной модели.
