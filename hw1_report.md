# ДЗ 1: мини-претрейн языковой модели

## Цель

Обучить языковую модель с нуля на русскоязычной Wikipedia, разобраться в подготовке данных и процессе pretrain, исследовать параметры обучения и проанализировать loss и генерации.

## Условия задания

- Датасет: `wikimedia/wikipedia`, конфигурация `20231101.ru`, split `train`.
- Первые 5000 примеров выделяются для оценки; остальные используются для обучения.
- Токенизатор: `ai-forever/rugpt3small_based_on_gpt2`.
- Максимальная длина последовательности: 512 токенов.
- Модель: Qwen3 примерно на 1 млрд параметров, инициализация с нуля. Архитектура должна соответствовать скелету задания.
- Обучение каждого эксперимента: 15 минут на одной GPU уровня NVIDIA A100 80 GB с ограничением времени через callback из скелета.
- Для сравнения экспериментов сохраняются параметры, графики loss, финальный `eval_loss`, примеры генераций и выводы.

Источник требований: [hw1.md](hw1.md).

Что учитываем при выполнении:

1. Pretrain обучает предсказанию следующего токена. Для анализа генераций используем начала текстов и проверяем их продолжения; способность отвечать на вопросы как чат-бот не является целью этого этапа.
2. Готовый токенизатор и случайно инициализированная модель — разные компоненты. Семинарский эксперимент с обучением собственного токенизатора не заменяет требование ДЗ использовать `ai-forever/rugpt3small_based_on_gpt2`.
3. При реализации causal language modeling проверяем согласование входов и целевых токенов. Нельзя одновременно вручную сдвинуть labels и оставить повторный сдвиг внутри модели; поведение конкретного класса модели проверим при реализации.
4. Помимо loss фиксируем скорость и число обработанных примеров/токенов: при одинаковом лимите времени настройки могут дать разный объём обучения. Это наш план сравнения, а не уже полученный результат.
5. Для одной GPU эффективный batch size равен `per_device_train_batch_size * gradient_accumulation_steps`.
6. Память расходуется на веса, градиенты, состояния оптимизатора и активации. `bf16` и gradient checkpointing исследуем как разные способы изменить расход памяти и скорость; эффект измеряем в нашем окружении.
7. Перед полными экспериментами проверяем подготовку данных и короткий цикл обучения. Для сравнения сохраняем одинаковое разделение данных и явно записываем изменяемые параметры.
