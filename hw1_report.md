# ДЗ 1: мини-претрейн языковой модели

## Цель

Обучить языковую модель с нуля на русскоязычной Wikipedia, разобраться в подготовке данных и процессе pretrain, исследовать параметры обучения и проанализировать loss и генерации.

## Условия задания

- Датасет: `wikimedia/wikipedia`, конфигурация `20231101.ru`, split `train`.
- Первые 5000 примеров выделяются для оценки; остальные используются для обучения.
- Токенизатор: `ai-forever/rugpt3small_based_on_gpt2`.
- Максимальная длина последовательности: 512 токенов.
- Модель: Qwen3 примерно на 1 млрд параметров, инициализация с нуля. Архитектура должна соответствовать скелету задания.
- Обучение каждого эксперимента: 15 минут на одной GPU уровня NVIDIA A100 80 GB с ограничением времени через callback из скелета.
- Для сравнения экспериментов сохраняются параметры, графики loss, финальный `eval_loss`, примеры генераций и выводы.

Источник требований: [hw1.md](hw1.md).
